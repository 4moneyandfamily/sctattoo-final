# Licences — fonts, icons, third-party code

Checked on 12 September 2026. Everything the site serves is either the shop's
own content or licensed for commercial use. There are no runtime dependencies.

## Fonts

All four are self-hosted from `assets/fonts/` (latin subset, WOFF2), fetched
from Google Fonts by `tools/fetch-fonts.mjs`. Self-hosting also means no
visitor IP is sent to a third party to render the page.

| Font | Used for | Licence | Commercial use | Source |
|---|---|---|---|---|
| Bungee | Headings, brand, social card | SIL Open Font License 1.1 | Yes, including embedding and web serving | David Jonathan Ross / Google Fonts |
| Archivo | UI text, buttons, captions | SIL Open Font License 1.1 | Yes | Omnibus-Type / Google Fonts |
| Newsreader | Body copy | SIL Open Font License 1.1 | Yes | Production Type / Google Fonts |
| Yellowtail | Script accents | Apache License 2.0 | Yes | Astigmatic / Google Fonts |

OFL 1.1 permits bundling, self-hosting and commercial use. It requires that
the font files are not sold on their own and that a Reserved Font Name is not
reused for a modified version. Neither applies here: the files are served
unmodified. Apache 2.0 permits commercial use with attribution, which this
file provides.

No font is subsetted, renamed or otherwise altered beyond Google's own
`latin` subset selection.

## Icons

There are none from a third party. The two icons in the interface — the
stacked-photos glyph on a multi-photo card and the close cross — are inline
SVG paths and a Unicode character written for this project. The favicon
(`assets/favicon.svg`) and touch icon are also original, generated by
`tools/build-og.mjs`.

## Third-party code

**Shipped to the browser: none.** No framework, no analytics, no tag manager,
no CDN script, no polyfill. `assets/js/app.js` is the whole runtime and it is
original work for this project.

Build and test tooling only, never served:

| Package | Role | Licence |
|---|---|---|
| sharp | Resize and re-encode photos | Apache License 2.0 |
| @playwright/test | Browser tests | Apache License 2.0 |
| serve (via npx) | Local preview server | MIT |

`npm audit`: **0 vulnerabilities** (12 September 2026).

## Map embed

The "Find the shop" panel embeds OpenStreetMap's public export frame. Map data
is © OpenStreetMap contributors, available under the Open Database License
(ODbL 1.0); the rendered tiles are CC BY-SA 2.0. The embed carries OSM's own
attribution inside the frame, which satisfies the licence. Nothing is cached,
re-hosted or re-rendered.

## Photographs

Every photo in `photos/` is the shop's own work, supplied for this rebuild.
No stock imagery is used. No image is AI-generated, retouched, redrawn or
"enhanced" — the only pixel operations applied were lossless-intent rotation,
resizing and re-encoding (see AUDIT.md).
